# PDF im ROWAPA-CI (nur auf Wunsch)

`build.py <quelle.md> <ziel.html> <Label>` erzeugt HTML im CI (TASA-Schriften und `logo.svg` im selben Ordner), `pdf.js` druckt es mit Chromium als A4-PDF.

Seit 25.10.2026 gibt es keine Backup-Runden mehr. Die laufend gepflegten Dokumente (`exports/00_start_hier.md`, `exports/00_entscheide.md`, `exports/07_benutzerhandbuch.md`) werden nur dann als PDF erzeugt, wenn ROWAPA etwas weitergeben möchte.
